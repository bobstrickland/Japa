# Japa Screen
To chant one round at a time, use either volume button.
To begin auto-chanting press the Start button.  To stop the auto-chanting press the Stop button.
To reset all counters (beads and rounds) press the Reset button.
To exit the app press the Exit button

The setting screen is accessed via the settings "gear" icon in the upper right corner of the screen.
The info screen is accessed by the "i" icon in the upper left corner of the screen (but it looks like you already know this since you're on this screen)

The Prayers screen can be accessed by swiping **left** from the main screen.
The User Prayers screen can be accessed by swiping **right** from the main screen.

When you're finished with the app and want to go back to using your volume buttons regularly, use the Exit button on the main screen.

Currently the auto-chanting function is only available if the Feedback is set to "Sound".  In thinking about this, I don't think it makes sense to auto-increment without the sound feedback.  If you think differently, please contact me and let me know how it makes sense and I'll make the change.
If you have ideas of things to add/change/etc... let me know.  I'm having a fun time playing around with this and making changes.

# Prayers
There are a number of mantras, prayers and songs that come pre-installed. You can select which one you want with the spinner at the bottom.
Some of them include aidio of the mantra being chanted for you.  The **Pray** button next to the spinner will be enabled if this is available for the selected mantra.

# User Prayers

You can add your own prayers, mantras and songs to the app, group them into sets, and share them
with other people. This guide covers the four screens involved.

Your prayer fills the screen, over its background image if you chose one.

| Control | What it does |
|---|---|
| **Sets** icon (top left) | Opens Prayer Sets. |
| **+** icon (top right) | Adds or edits a prayer, starting from the one on screen. |
| **Name list** (bottom) | Jump to any prayer. |
| **◀ ▶** | Step to the previous or next prayer, in order. |

**What you see here** depends on the set chosen on the Prayer Sets screen. Choose **All prayers**
to see everything by name, or choose a set to see just that set, in its own order — use **◀ ▶** to
work through it. The app remembers your place, so you come back to the prayer you left.

If the screen is empty, tap **+** to add your first prayer.

---

## Creating and sharing

1. **Write it.** Type or paste the words on the Add / Edit screen and give it a name.
2. **Group it.** On Prayer Sets, make a set — "Sunday Assembly", "Diwali", "Morning" — and put your
   prayers in the order you actually perform them.
3. **Share it.** Show a QR code for people in the room, or send a `.japa` file to anyone.
4. **Receive it.** Scan or open what someone sends you. You see what is in it before anything is
   added, and you decide what happens to prayers you already have.

The same prayer can be in as many sets as you like, in a different position in each. Removing it
from a set never deletes the prayer, and deleting a set never deletes its prayers.

---

## What a shared set contains

Each prayer in a set carries:

- **Name** — must be unique. This is how the app recognises a prayer, including one arriving from
  someone else.
- **Text** — the words.
- **Background image** — optional, and only included when sharing by file.

The set carries its **name** and the **order** of its prayers, so it is rebuilt exactly as sent.

---

## The two ways to share

### QR code — for people in the room

Tap **Show QR** on Prayer Sets to share a whole set, or **Export** on the Add / Edit screen to
share the one prayer on screen. Everyone else taps **Scan QR** and points their camera at it. The
screen brightens automatically so the code scans from a distance.

- **Best for:** an assembly, a class, anyone sitting in front of you. Nothing is sent anywhere, no
  internet, no accounts.
- **Limits:** background images are **not** included — the words travel, the picture does not.
  There is also a size limit; if a set is too long the app tells you how far over it is and you
  should use **Share set** instead. The other person needs a camera and needs to be able to see
  your screen.

### `.japa` file — for sharing at a distance

Tap **Share set** on Prayer Sets and send the file however you like — message, email, cloud drive.
The other person opens it, or taps **Import** and picks it.

- **Best for:** anyone not in the room, and anything too big for a QR code. This is the **only** way
  to share background images, and it doubles as a backup of a set.
- **Limits:** you need a way to send it, and the other person has to open an attachment. Some apps
  do not recognise the file when it arrives — if tapping it does nothing, use the **Import** button
  and pick the file yourself.

## Add / Edit Prayer

Reached with **+** from My Prayers. The counter at the top right shows where you are — `3 / 12`, or
**New** for a prayer you have not saved yet.

| Field | Notes |
|---|---|
| **Name** | Required, and no two prayers can share a name. |
| **Background image** | Optional. Shows a preview once chosen. |
| **Prayer text** | The words. Type or paste them. |

| Button | What it does |
|---|---|
| **✕** (top left) | Leaves the screen. |
| **Choose image…** | Pick a picture for the background. It is copied into the app, so deleting the original photo later does no harm. |
| **Previous / Next** | Move through your saved prayers, in name order. |
| **Delete** | Deletes the prayer on screen. You are asked to confirm first, and it cannot be undone — the prayer is removed from your list and from every set it was in. Greyed out for a prayer you have not saved yet. |
| **Export** | Shows this one prayer as a QR code for someone else to scan — exactly as it appears on screen, including anything you have just typed. |
| **Import** | Opens the camera to scan someone else's QR code. |
| **Add** | Clears the form for a new prayer. |
| **Save** | Saves your changes. |
| **Cancel** | Undoes your unsaved changes. With nothing to undo, it closes the screen. |

If you have unsaved changes, the app asks before letting you move away or leave.

While you are typing, the buttons hide to give the words the whole screen — they come back when you
close the keyboard.

**Delete** removes the prayer altogether. To take a prayer out of one set but keep it, use the
**✕** next to it on the Prayer Sets screen instead.

## Prayer Sets

Reached with the **Sets** icon from My Prayers.

The list at the top chooses the set you are working on — **and it is also what My Prayers shows**.
Choose **All prayers** to go back to seeing everything.

| Button | What it does |
|---|---|
| **New** | Creates a set and asks for a name. |
| **Rename** | Renames the chosen set. |
| **Delete** | Deletes the set. Your prayers are kept. |
| **Add prayers** | Tick any prayers not already in the set; they are added at the end, in the order you tick them. |
| **Share set** | Sends the set as a `.japa` file, with its background images. |
| **Show QR** | Displays the set as a QR code for others to scan. |
| **Scan QR** | Opens the camera to scan someone else's code. |
| **Import** | Pick a `.japa` file to add. |

Below the buttons is the set's prayers, numbered in the order they will be read:

| Row control | What it does |
|---|---|
| **▲ ▼** | Move a prayer up or down the order. |
| **✕** | Take it out of this set. The prayer itself is kept. |

Rename, Delete, Add prayers, Share set and Show QR are greyed out under **All prayers** — pick a
set first.

---

## Import prayers

This screen appears whenever prayers arrive — from a scan, from a file you opened, or from the
**Import** button. **Nothing is added until you tap Import**, so you can always look and cancel.

It shows the set's name, how many prayers are in it, and a list of every prayer name.

If you already have prayers with the same names, they are listed and you choose:

- **Keep my versions** — your wording is untouched; the incoming ones are ignored. The set is still
  built, using the prayers you already have.
- **Replace with the imported versions** — the incoming wording wins.

Prayers you do not already have are always added. Nothing is ever duplicated.

Tap **Import** to apply, or **Cancel** to discard. A message confirms what happened — how many were
added, replaced and kept. If the set has a name, it is created on your device too, in the order it
was shared.
